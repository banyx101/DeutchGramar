2.1

Separable Verbs (Trennbare Verben)

Sentence Bracket Rule

Prefixes such as an-, auf-, aus-, ein-, zu-, mit-, weg-, vor- detach from the stem in simple present sentences and move to the very end of the clause. When a modal verb (müssen, sollen, können, möchten, wollen) takes Position 2, the separable verb stays together in its infinitive form at the end.

Structure A · Simple Present (Splits)
Subject + Stem (Pos. 2) + Object + Prefix (End)
  • Der Vater macht das Licht aus.The father turns the light off.
  • Ich rufe meine Schwester an.I call my sister.
  • Meine Frau macht den Kühlschrank zu.My wife closes the refrigerator.
Structure B · With Modal Verb (Stays Together)
Subject + Modal (Pos. 2) + Object + Infinitive (End)
  • Der Vater muss das Licht ausmachen.The father has to turn the light off.
  • Kannst du das Fenster aufmachen?Can you open the window?
  • Ich schalte das Radio ein → Ich will das Radio einschalten.Switch on (present vs. modal).
Key Opposite Pairs: anmachen / ausmachen (turn on / off) · einschalten / ausschalten (switch on / off) · aufmachen / zumachen (open / close) · einsteigen / aussteigen (board / exit) · aufwachen / aufstehen (wake up / get up)
2.2

Preposition & Case Decision Flowchart

Akkusativ Dativ Wechsel
Branch 1 · Always Akkusativ
Akkusativ Only
durch für ohne gegen um bis entlang

Only Masculine changes: der → den, ein → einen. Note: entlang goes after the noun: „Ich laufe die Donau entlang / den Fluss entlang.“

Branch 2 · Always Dativ
Dativ Only
aus bei mit nach von zu gegenüber seit ab

All genders shift: m/n → dem/einem, f → der/einer, pl → den + -n. Contractions: zum (zu+dem), zur (zu+der), beim (bei+dem), vom (von+dem).

Branch 3 · Two-Way (Wechsel)
Wo? Dativ / Wohin? Akkusativ
in an auf unter über vor hinter neben zwischen

Ask Wo? (static location, no A→B) → Dativ (im, am). Ask Wohin? (movement A→B) → Akkusativ (ins, ans, aufs).

Gender / Number Nominativ (Base) Akkusativ (Direct / Wohin?) Dativ (Static / Indirect) Key Contractions
Masculine (m) der / ein / mein Bahnhof den / einen / meinen Bahnhof dem / einem / meinem Bahnhof zu+dem = zum, bei+dem = beim, in+dem = im
Feminine (f) die / eine / meine Post die / eine / meine Post der / einer / meiner Post zu+der = zur („zur Post“)
Neuter (n) das / ein / mein Stadion das / ein / mein Stadion dem / einem / meinem Stadion in+das = ins (Akk), in+dem = im (Dat), zu+dem = zum
Plural (pl) die / — / meine Kinder die / — / meine Kinder den / — / meinen Kindern (+ -n) mit den Männern, mit den Kindern, mit den Frauen
Time Trap · seit vs. ab (Dativ):
seit = started in the past, still continuing now: „Ich bin seit Freitag auf Urlaub.“ / „seit 11 Jahren“.
ab = starts in the future: „Ich bin ab Freitag auf Urlaub.“
Person & Place Trap · zu vs. bei (Dativ):
zu = movement A→B: „Ich gehe zu Peter / zum Arzt / zur Ärztin.“
bei = static presence (no A→B): „Ich bin bei Peter / beim Arzt / beim Billa.“

2.3

Positional Verb Matrix (Wo? vs. Wohin?)

Wo? = Static (Dativ) Wohin? = Action (Akkusativ)

Four verb pairs govern position in German. The static verbs (liegen, stehen, sitzen, hängen, sein) describe where something already is (no A→B movement → Dativ). The action verbs (legen, stellen, setzen, hängen) describe putting something there (A→B movement → Akkusativ).

Orientation Static Verb · Wo? (Dativ) Action Verb · Wohin? (Akkusativ) Source Example Pair
Flat / Horizontal liegen (to be lying) legen (to lay flat) Das Hemd liegt auf dem Teppich. ↔ Dominik legt das Hemd auf den Teppich.
Upright / Vertical stehen (to be standing) stellen (to place upright) Der Tennisschläger steht auf dem Polster. ↔ D. stellt ihn auf den Polster.
Seated sitzen (to be sitting) setzen (to seat) Dominik sitzt zwischen dem Tisch und dem Schrank. ↔ D. setzt das Kind zwischen den Tisch und den Schrank.
Suspended / Wall hängen (to be hanging) hängen (to hang up — same form) Die Krawatte hängt am (an dem) Schlüssel. ↔ D. hängt die Krawatte an den Schlüssel.
General Location sein (to be located) (no action counterpart) Wo ist das Buch? — Das Buch ist unter dem Sessel.
2.4

City Directions & Transit (Wegbeschreibung)

zu + Dativ
Question 1 · Asking If Something Exists Nearby

„Entschuldigung, gibt es hier in der Nähe …?“

es gibt always triggers Akkusativ with an indefinite article (einen / eine / ein):

  • … einen Bankautomaten / einen Supermarkt / einen Park? (m)
  • … eine Apotheke / eine Bank / eine Polizeistation? (f)
  • … ein Café / ein Krankenhaus / ein Restaurant? (n)
Question 2 · Asking How to Reach a Destination

„Entschuldigung, wie komme ich …?“

kommen zu always triggers Dativ! Watch gender contractions carefully:

  • der Bahnhof (m) → zu + dem = zum Bahnhof / zum Hauptbahnhof
  • das Stadion (n) → zu + dem = zum Stadion / zum Burgtheater
  • die Post (f) → zu + der = zur Post / zur Bibliothek / zur U-Bahn
Direction Phrase Case Rule Complete Example
geradeaus gehen / die … Straße entlang Akk (entlang) Gehen Sie noch ein Stück geradeaus / die Hauptstraße entlang.
vorbeigehen an + … Dativ Gehen Sie am (an dem) Rathaus / an der Kirche vorbei.
die [Ordinal] Straße links/rechts nehmen Akkusativ Nach der Telefonzelle nehmen Sie die erste / zweite / dritte Straße links.
abbiegen an / bei + … Dativ Biegen Sie an der zweiten Ampel / an der dritten Kreuzung rechts ab.
über + … / durch + … Akkusativ Gehen Sie über die Straße / den Platz. Gehen Sie durch den Park.
bis zu + … / gegenüber + … Dativ Gehen Sie bis zur nächsten Ampel. Die Bank ist gegenüber der Post.
fahren mit + … (Public Transit) Dativ Fahren Sie mit dem Bus / der Straßenbahn / der U-Bahn / dem Taxi.
Ordinal Numbers Rule: Numbers 1–19 take -te (erste, zweite, dritte, vierte, fünfte, sechste, siebte/siebente); numbers 20+ take -ste (zwanzigste, einundzwanzigste). Polite closings: Keine Ursache! · Gern geschehen! · Kein Problem! · Bitte, gerne!
2.5

Perfekt Past Tense (Schwache / Regular Verben)

haben + Partizip II

Used in everyday conversation to describe completed past actions. The conjugated auxiliary haben occupies Position 2, while the past participle (Partizip II) locks into the very end of the sentence.

Subject + haben (ich habe, du hast, er/sie/es hat, wir haben, ihr habt, sie/Sie haben) + … + ge-[stem]-t
Standard Weak Verb Stem (+ ge- … -t)

Remove -en to find the stem, add ge- in front and -t at the end:

  • duschen (stem: dusch) → Ich habe gestern fünf Minuten geduscht.
  • kaufen → gekauft · lernen → gelernt · kochen → gekocht · tanzen → getanzt
Special Consonant Stems (+ ge- … -et)

If the stem ends in -t, -d, -chn, -gn, or -tm, insert an extra -e- before -t for pronunciation:

  • antworten → geantwortet · arbeiten → gearbeitet · kosten → gekostet
  • reden → geredet · rechnen → gerechnet · regnen → geregnet · atmen → geatmet
